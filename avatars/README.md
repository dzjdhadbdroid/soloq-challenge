# Photos de profil

Dépose ici une photo par joueur. Le nom du fichier doit être le **prénom du joueur tel qu'il est écrit
dans `players.json`** (sans espaces ni accents, majuscules ou minuscules sans importance) :

| Joueur dans players.json | Fichier à déposer |
|---|---|
| `"name": "Kuro"` | `avatars/kuro.png` (ou `.jpg`, `.jpeg`, `.webp`, `.gif`) |
| `"name": "KING VON"` | `avatars/kingvon.png` |

Conseils : image carrée, 256 × 256 px environ, moins de 500 Ko (maximum 1 Mo).
Le site se met à jour tout seul 1 à 2 minutes après l'ajout. Pour remplacer une photo, dépose le nouveau fichier avec le même nom.
